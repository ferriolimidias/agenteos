# Frontend releases

Build and publish one complete panel artifact graph from the release source. The panel has one React root in `src/main.jsx`. Replacing selected chunks across builds can import an old entrypoint as a helper module and execute its `createRoot(#root)` side effect again (Issue #16).

`npm run build` produces `dist`. `npm run validate:artifacts` verifies its HTML, local static/dynamic literal import graph, assets and exactly one mount on `#root`. `npm run test:artifacts` covers mixed-entrypoint and missing-asset regressions. The Docker panel build runs this gate automatically. Also audit the assembled image's HTML/assets before release. The generic React Router nonliteral loader is reported separately and cannot be resolved by static analysis; browser smoke verifies the actual panel routes.

Run `npm run test:panel-smoke` with `PANEL_ORIGIN` pointing to the candidate. Every API call uses synthetic browser fixtures; WebSockets and external origins are blocked. No real session or token is needed. `PANEL_SMOKE_MODE=public-readonly` checks public rendering without a session and permits only the optional public branding GET. `PANEL_EVIDENCE` and `PANEL_SCREENSHOT` save sanitized evidence. Install Playwright's Chromium in the test environment, or specify `PLAYWRIGHT_EXECUTABLE_PATH`.

The Dockerfile defaults to the official nginx base. For a minimal release retaining the current nginx and cached hashed assets for existing tabs, build with `--target panel_release` and set `PANEL_RUNTIME_BASE` to the approved current frontend image. This target preserves Anamnese and nginx byte-for-byte and refuses a base without the existing Anamnese app. Copy the complete new `dist`, then validate the assembled graph: retained historical files must be unreachable from the new panel entrypoint. Anamnese and nginx must match their approved runtime. Existing tabs still executing the faulty old entrypoint require a reload; do not monkeypatch React or swallow DOM errors.

Deploy only the frontend container after protected baselines, browser navigation and independent review pass. Keep the previous image/container available. Preserve the original backend DNS alias, host port, network and restart policy. Roll back to the previous frontend if public smoke or health fails. Never use `docker compose down` or restart backend/database/Redis/Evolution for a panel release.
